=== TITRE (max 30 caractères) ===
SonyScreen — moniteur USB

=== DESCRIPTION COURTE (max 80 caractères) ===
Live view plein écran d’un Sony Alpha en USB-C (PC Remote).

=== DESCRIPTION COMPLÈTE ===
SonyScreen transforme un téléphone ou une tablette Android compatible USB-C OTG en moniteur pour appareil photo Sony Alpha en mode PC Remote.

Fonctions
• Live view plein écran, paysage
• Miroirs horizontal, vertical et rotation 180°
• Verrouillage tactile (appui long 2 secondes)
• Inversion paysage / paysage inverse
• Reprise du flux après déclenchement (purge de l’objet photo en mémoire)

Prérequis
• Boîtier Sony compatible PTP / PC Remote (testé sur A7R III)
• Câble USB-C data (pas charge seule)
• Mode PC Remote
• Ctrl avec smartphone désactivé
• Destination d’enregistrement : PC + boîtier
• Format RAW seul recommandé
• Affichage auto (revue après photo) désactivé
